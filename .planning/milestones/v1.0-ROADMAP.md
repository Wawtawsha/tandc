# Milestone v1.0: Town & Country Furniture Website

**Status:** SHIPPED 2026-03-03
**Phases:** 1-8
**Total Plans:** 21

## Overview

This roadmap delivered a local furniture store website for Town & Country in Farmville, VA. The site exists to do one thing: when someone searches for furniture in Farmville, they find Town & Country, see what is available, trust the local store, and either call or walk in. Built from Shrike Media's Next.js 16 + Tailwind CSS 4 template, the site showcases La-Z-Boy and Ashley product lines under Town & Country's own brand identity, emphasizing local trust and personal service as the competitive advantage over corporate e-commerce.

## Milestone Summary

**Key Decisions:**
- Store-brand-primary identity (avoids La-Z-Boy vs Ashley color clash)
- Clone from Shrike template (proven production codebase)
- Hardcoded content over CMS for v1
- Free font alternatives over licensed brand fonts
- No e-commerce (local showroom value proposition)
- Server Components by default, Client Components only at interaction boundaries
- oklch color system with placeholder strategy for missing product images
- GA4 event tracking with client component wrappers for Server Component integration
- focus-visible (not focus) for keyboard-only accessibility indicators

**Issues Resolved:**
- React 19 compliance: useReducedMotion rewritten to useSyncExternalStore, useScrollReveal refactored
- TrustStrip heading hierarchy: h3 changed to span to avoid skipping h2
- M-dashes removed from site copy per client preference

**Issues Deferred:**
- Product photography (oklch placeholders in place, Next.js Image infrastructure wired)
- Actual Ashley marketing video IDs (using placeholder YouTube IDs)
- About page photos (3 slots ready for client-provided imagery)
- Google Maps API key, GA4 measurement ID, Resend API key (graceful fallbacks working)

**Technical Debt Incurred:**
- None significant. Clean codebase with 2,634 LOC across 45 source files.
