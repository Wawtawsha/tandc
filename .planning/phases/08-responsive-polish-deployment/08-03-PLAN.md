**Step 1: Run production build locally.**

Run `npm run build` in the project root. This MUST succeed with zero errors. If there are build errors, fix them (likely TypeScript or import issues). Common issues to watch for:
- Missing module imports
- Type errors that only surface in production mode
- Dynamic import issues

If build succeeds, run `npm run start` and briefly verify the homepage loads at http://localhost:3000 (the dev server must be stopped first).

**Step 2: Create .env.example file.**

Create `.env.example` documenting all environment variables the project uses. This file is committed to git (no secrets) so future developers know what to configure:

```
# Google Analytics 4 - Measurement ID
# Get from: Google Analytics -> Admin -> Data Streams -> Measurement ID
# Format: G-XXXXXXXXXX
# Optional: Site works without it (tracking disabled)
NEXT_PUBLIC_GA_MEASUREMENT_ID=

# Google Maps Embed API Key
# Get from: Google Cloud Console -> APIs & Services -> Credentials
# Enable "Maps Embed API" for this key
# Optional: Site shows address with "View on Google Maps" link as fallback
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=

# Resend Email API Key
# Get from: resend.com -> API Keys
# Required for contact form email delivery
# Without it: form submissions will fail gracefully with error message
RESEND_API_KEY=
```

**Step 3: Verify .gitignore includes .env.local.**

Check that `.gitignore` contains `.env.local` and `.env*.local` entries. If not, add them. This prevents accidental secret commits.
