**Implementation details:**

1. Import `Link` from `next/link` for internal navigation links.

2. Section headings: Use `<h2>` elements (semantically correct for landmark sections in a footer). Style with display font: `className="text-lg font-semibold mb-4" style={{ fontFamily: 'var(--font-display)' }}`. Use `text-foreground` color for headings.

3. Store hours list: Render as `<dl>` (definition list) for semantic correctness -- days are terms, hours are definitions. Alternative: a simple `<ul>` is also acceptable. Use `text-sm text-muted` for hours text, `font-medium text-foreground` for day labels.

4. Phone number: Render as `<a href="tel:+14342238163">` with display text `(434) 223-8163`. Add aria-label: `"Call Town and Country Furniture at 4 3 4, 2 2 3, 8 1 6 3"`. Style with `hover:text-accent transition-colors`.

5. Address: Plain text, no link (directions link will come in Phase 6). Format:
   ```
   5301 Farmville Rd
   Farmville, VA 23901
   ```
   Use a `<br />` or two separate `<span>` elements for the line break.

6. Quick links: Render as `<ul>` with `<li>` > `<Link>` for each. Style links with `text-sm text-muted hover:text-accent transition-colors`. These are secondary navigation, NOT duplicating the header -- they serve users who scrolled to the bottom.

7. Copyright bar: Separated by `border-t border-border-subtle mt-8 pt-6`. Centered text: `&copy; {currentYear} Town & Country Furniture. All rights reserved.`

8. Footer element: Keep the existing `<footer>` tag. Add `role` is unnecessary (footer element is implicit). Add `aria-label="Site footer"` for explicit labeling. Use `bg-surface` for a subtle background distinction from the main content area. Keep `border-t border-border-subtle` from the existing stub. Increase padding: `py-12` (not py-8) for breathing room.

9. Responsive: `grid grid-cols-1 md:grid-cols-3 gap-8` handles mobile stacking. On mobile, each column stacks vertically with gap-8 spacing. On md+, three columns side by side.

10. Sunday "Closed" should use `text-muted` to visually de-emphasize it.
