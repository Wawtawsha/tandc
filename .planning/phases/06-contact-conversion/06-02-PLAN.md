**Step 3: Create Zod validation schema** at `lib/validations/contact.ts`:
- Export `contactSchema` using `z.object()`
- Fields:
  - `name`: `z.string().min(2, 'Name must be at least 2 characters')`
  - `email`: `z.string().email('Please enter a valid email address')`
  - `phone`: `z.string().optional()` (no validation on format -- keep it simple)
  - `message`: `z.string().min(10, 'Message must be at least 10 characters')`
- Export the inferred type: `export type ContactFormData = z.infer<typeof contactSchema>`
- Export the action state type:
  ```typescript
  export type ActionState = {
    message: string;
    errors: Record<string, string[]>;
    success: boolean;
  };
  ```

**Step 4: Create Server Action** at `app/actions/contact.ts`:
- Top of file: `'use server'`
- Import `contactSchema` and `ActionState` from `@/lib/validations/contact`
- Import `Resend` from `resend`
- Create resend instance: `const resend = new Resend(process.env.RESEND_API_KEY)`
- Export `submitContactForm(prevState: ActionState, formData: FormData): Promise<ActionState>`
  1. Extract fields from formData using `.get()` -- cast to string
  2. Validate with `contactSchema.safeParse()`
  3. If validation fails: return `{ message: 'Please correct the errors below.', errors: validatedFields.error.flatten().fieldErrors, success: false }`
  4. If validation passes: send email via `resend.emails.send()`:
     - from: `'Town & Country Website <onboarding@resend.dev>'` (Resend default sender for dev -- custom domain in Phase 7)
     - to: `[process.env.STORE_EMAIL || 'info@townandcountryfurniture.com']`
     - replyTo: validated email
     - subject: `Contact Form: ${name}`
     - text: formatted plain text with name, email, phone (or "Not provided"), and message
  5. If Resend returns error: log it, return `{ message: 'Failed to send message. Please call us at (434) 223-8163.', errors: {}, success: false }`
  6. On success: return `{ message: "Thank you! We'll get back to you within 24 hours.", errors: {}, success: true }`
  7. Wrap the Resend call in try/catch for network errors

Do NOT add a honeypot field yet -- keep it simple. Add spam prevention only if needed later.
