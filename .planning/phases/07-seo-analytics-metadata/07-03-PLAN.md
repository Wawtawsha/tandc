  4. Add an `onIframeAdded` callback to LiteYouTubeEmbed that fires the custom video_play event AND calls the optional onPlay prop:

  **ContactForm.tsx (already a Client Component):**
  1. Import sendGAEvent from '@next/third-parties/google'
  2. Add a useEffect that fires form_submit_success when state.success becomes true:
  ```tsx

    if (state.success) {
      formRef.current?.reset();
      sendGAEvent('event', 'form_submit_success', {
        form_name: 'contact',
        form_location: 'contact_section',
      });
    }
  }, [state.success]);
  ```
  This replaces the existing useEffect that only resets the form. Combine both behaviors.
  3. Wrap the form's action to also fire a form_submit attempt event. Since the form uses `action={formAction}` (Server Action), add an onSubmit handler:

  ```tsx
    onSubmit={() => {

        form_location: 'contact_section',
      });
    }}
    className="space-y-5"
  >
  ```
  The onSubmit fires before the Server Action. This tracks the attempt. The useEffect tracks the success. Together they give conversion funnel data (attempts vs successes).

  | Event Name | Parameters | Type | Fired When | Component | File |

  | form_submit_success | form_name (string: contact), form_location (string: contact_section) | Custom | Server action returns success | ContactForm | components/contact/ContactForm.tsx |
