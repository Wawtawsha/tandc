Create `data/products.ts` at the project root (NOT src/data -- this project has no src/ directory; the tsconfig paths alias `@/*` maps to `./*`).

Define the Product type system:

```typescript
export interface BaseProduct {
  id: string;
  brand: 'lazboy' | 'ashley';
  name: string;
  category: 'recliner' | 'sofa' | 'sectional' | 'lift-chair' | 'living-room' | 'bedroom';
  image?: string;          // Path in /public or undefined for placeholder
  imageAlt: string;
  featured: boolean;
  priceNote?: string;      // "See in store for pricing", "Starting at $X"
}

export interface LaZBoyProduct extends BaseProduct {
  brand: 'lazboy';
  bestseller?: boolean;
}

export interface AshleyProduct extends BaseProduct {
  brand: 'ashley';
  collection?: 'Next-Gen' | 'Nuvella' | 'Outdoor';
}

export type Product = LaZBoyProduct | AshleyProduct;
```

Key design decisions:
- `image` is OPTIONAL (undefined means show oklch placeholder). Do NOT use a magic string like "placeholder" -- just omit the field.
- `category` values match the anchor IDs from CategoryGrid.tsx: recliner, sofa, sectional, lift-chair, living-room, bedroom.
- No `price: number` field -- local furniture stores typically don't show exact prices online. Only `priceNote` string.

Populate with 8-10 sample products (a mix of La-Z-Boy and Ashley):
- La-Z-Boy: 4-5 products across recliners, sofas, lift chairs. Mark 3 as `bestseller: true`.
- Ashley: 4-5 products across sofas, sectionals, living room, bedroom. Use `collection` field for Next-Gen and Nuvella items.
- ALL products should have `image: undefined` (no product images exist yet in /public). Set `featured: true` on most.
- Use descriptive `imageAlt` even without images (accessibility prep for when photos arrive).
- Use `priceNote: 'See in store for pricing'` as default.

Add filter helper functions (exported, named):

```typescript
export const getLaZBoyBestSellers = (): LaZBoyProduct[] =>
  products.filter((p): p is LaZBoyProduct => p.brand === 'lazboy' && p.bestseller === true);

export const getAshleyCollections = (collection?: AshleyProduct['collection']): AshleyProduct[] =>
  products.filter((p): p is AshleyProduct =>
    p.brand === 'ashley' && (collection ? p.collection === collection : true)
  );

export const getAshleyFeatured = (): AshleyProduct[] =>
  products.filter((p): p is AshleyProduct => p.brand === 'ashley' && p.featured);

export const getFeaturedByCategory = (category: Product['category']): Product[] =>
  products.filter((p) => p.category === category && p.featured);
```

These helpers are the ONLY way components should access products. Components import helpers, never filter the raw array themselves.

```tsx
{product.image ? (
  <Image
    src={product.image}
    alt={product.imageAlt}
    fill
    sizes="(max-width: 768px) 100vw, (max-width: 1200px) 50vw, 33vw"

  <div
    className="w-full h-full flex flex-col items-center justify-center gap-2"
    style={{ backgroundColor: categoryColors[product.category] }}
  >
    {/* Inline furniture SVG icon (couch silhouette) */}
    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="1.5" className="w-12 h-12 text-white/60">

      <path d="M2 11v5a2 2 0 0 0 2 2h16a2 2 0 0 0 2-2v-5a2 2 0 0 0-4 0v2H6v-2a2 2 0 0 0-4 0Z" />

      <path d="M20 18v2" />
    </svg>
```

This uses a falsy check: `product.image` is falsy for both `undefined` and empty string `""`, so both cases correctly fall through to the placeholder. Do NOT use `product.image !== undefined` -- the falsy check is more defensive.

Use `placeholder="blur"` on `<Image>` ONLY for static imports -- since we're using string paths, omit placeholder prop for now.
